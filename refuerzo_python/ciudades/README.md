# Retos para hacer el fin de semana

## Básicos
Realizar la siguiente funcionalidad sobre el código suministrado:
- Mostrar al final del proceso estadísticas del número de filas procesadas satisfactoriamente y con errores.
- Clasificar los errores de una manera más eficiente y limpia en una estructra de datos. Cada código de error tendrá una descripción dada. No se hardcodeará en el print.
- Se creará un nuevo tipo de error sobre la dirección. Todas tendrán que tener un tipo de vía que será Calle o Avenida (solo habrá de esos dos tipos) y tendrá la estructura "Calle XXXXXX, número" o "Avenida XXXXXXXX, número".

## Avanzados
- El output del programa se generará en ficheros, en el subdirectorio `output`.
    + errores.txt
    + personas.txt
    + estadisticas.txt

- Crea nueva estadísticas para saber cuántas personas se han procesado correctamente para cada ciudad:
    + Madrid: 12
    + Barcelona: 8
    + etc.
